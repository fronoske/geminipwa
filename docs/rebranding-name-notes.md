# リブランディング名称検討メモ

更新日: 2026-08-03

## 状態

名称は未決定。候補を急いで確定せず、後日この文書から検討を再開する。

## 背景

現在の `GeminiPWA` という名称は、「Gemini専用の簡易PWA」という印象を与える。一方、現在のアプリは複数のLLMプロバイダー、OpenRouter、長期セッション、Lorebook、プロンプト管理などを備えており、実態との乖離が大きい。

新しいブランドでは、一般的なLLMクライアントよりも、次の価値を前面に出す。

- LLMとのロールプレイ
- 登場人物と世界設定を保った長い対話
- 小説・群像劇・物語体験
- Lorebookによる設定と記憶の継続
- 特定のLLMプロバイダーに依存しないこと

## 名称に求める性質

- ロールプレイまたは小説を連想できる
- 特定のジャンル（ファンタジー、学園など）に限定されない
- 発音しやすく、画面上で扱いやすい
- ASCIIのリポジトリ名、ファイル接頭辞、DB名にも展開しやすい
- `AI`、`Gemini`、`PWA` など、将来変わり得る技術をブランド名の中心に置かない

## 既存名称との衝突に関する暫定調査

以下は意味としては適しているが、既に物語・AI・アプリ分野で目立つ使用例があるため、有力候補から外した。

- `TalePlay`: インタラクティブストーリーアプリが存在する
- `StoryPlay`: 複数のインタラクティブストーリー／AI関連サービスで使われている
- `Dramatis`: AIサービス名として使われている
- `Castory`: 複数のアプリ・AIサービスで使われている
- `Playlogue`: AI/MLアカウントやゲーム出版社で使用例がある

参考:

この調査は一般的なWeb検索による予備調査であり、商標・法人名・ドメイン・パッケージ名の正式なクリアランス調査ではない。

## ブランド名と技術識別子

ブランド名と内部識別子を完全に別名にする案も出た。ただし、検索性と保守性を考えると、可能なら同じ語の大小文字・記号違いに留めるのが望ましい。

例として `Lorelogue` を採用する場合:

- 表示名: `Lorelogue`
- アイコンや狭いUIでの短縮表記: `LL`
- リポジトリ名: `lorelogue`
- エクスポート接頭辞: `lorelogue-*`
- DB名: `Lorelogue_DB`
- コード内のブランド識別子: `lorelogue`

なお、`geminipwa` と `lorelogue` はどちらも9文字であり、ファイル名やリポジトリ名として後者が特に長いわけではない。

## 技術的なリブランディング残件

- 新しい正式名称と表記を決定する
- 画面内の製品名、PWA manifest、README、アイコン、説明文を変更する
- GitHubリポジトリ名とリンクを検討する
- `GeminiPWA_DB` を新しいDB名へ変更する
- `geminipwa-{settings,sessions,lorebooks}-{yyyymmdd}.json` の接頭辞を変更する
- 設定JSONの `app: "GeminiPWA"` に新識別子を導入する
- Lorebook JSONの `format: "GeminiPWA Lorebook"` に新識別子を導入する
- Service Workerやキャッシュ名などに旧ブランドが残っていないか全体検索する
- 旧DBから3種類のエクスポートを経由して新DBへ復元する実ブラウザ試験を行う

## 互換性について決定済みの方針

- DB名変更時は旧DBを自動移行せず、設定・Lorebook・セッションのエクスポート／インポートで移行可能にする
- 旧 `GeminiPWA` 設定形式と `GeminiPWA Lorebook` 形式は、新ブランド導入後もインポート可能にする
- Lorebookはインポート時に元のIDを維持する
- 未登録Lorebookを参照するセッションでもLorebook IDを保持し、セッションを開いた際に警告する
- 同じIDのLorebookを後からインポートすれば、セッションとの関連が復活する
- 添付テキストファイルは現在のセッションJSONに本文が含まれる。画像・PDF等のバイナリ本体を移行対象に加える変更は、現時点では行わない
