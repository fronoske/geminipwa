# 実装要件

## Google Analytics

- GitHub Pages 用の `index.html` には GA4 測定 ID `G-LYK4N70WLR` を設定し、Google タグでページビューを計測する。
- `GA_MEASUREMENT_ID` 環境変数でビルド時の測定 ID を変更できるようにする。
- チャット名を含む動的なページタイトルと URL のクエリ文字列を Analytics へ送らない。
- `GA_MEASUREMENT_ID` に空文字列を指定したビルドでは Google タグを含めない。
- Service Worker のキャッシュを更新し、既存の PWA インストールにも新しい公開用 HTML を届ける。

## チャット入力

- 入力が空で添付ファイルもなく「送」ボタンが非アクティブの場合、そのボタン領域をタップするとチャットを最下部までスクロールする。
- 非アクティブな「送」ボタン以外の入力欄、貼り付けボタン、フッター領域の既存操作には影響させない。

## 入力プリセット

- 入力プリセットツールバーは、設定画面の「入力プリセット」にある「常に表示」が未選択の場合、入力欄が空または空白文字だけの状態でフォーカスされたときに表示する。
- 「常に表示」が選択されている場合、入力欄の内容にかかわらず、入力欄がフォーカスされたときにツールバーを表示する。この設定は保存し、次回起動時にも復元する。
- プリセット本文にカーソル位置指定 (`{|}`) がない場合、プリセット文字列を入力済みテキスト全体の直後へ追加する。
- プリセット本文にカーソル位置指定 (`{|}`) がある場合、マーカーを除いたプリセット文字列を入力欄へ配置し、入力済みテキスト全体をマーカー位置へ移動する。処理後のカーソルは、移動した入力済みテキストの直後に置く。

## 検索・置換

- メイン画面のハンバーガーメニューに「検索・置換」を追加する。
- メニュー選択時に、検索ワード、置換ワード、検索対象（全体／編集中の応答）、置換方法（一括置換／逐次置換）、OK、Cancel を備えたダイアログを表示する。
- 検索は大文字・小文字を区別するリテラル検索とし、空の検索ワードは受け付けない。
- 対象となるテキストは、現在表示しているセッションのメッセージ本文 (`currentMessages[].content`) とする。カスケード応答は選択中の応答だけを対象とし、添付ファイル名、思考要約、チャットタイトル、メモは対象外とする。
- 「編集中の応答」は、既存のメッセージ編集を開始している場合だけ選択できる。検索には編集 textarea の未保存内容を使用する。
- 一括置換は選択した検索対象に含まれる全一致箇所を置換し、チャットを保存してから「n件置換しました」と表示する。n は置換した一致箇所数とする。
- 逐次置換は対象メッセージをセッション先頭から検索し、一致箇所を編集 textarea 上で選択表示する。下部バーに「置換？ Yes / No / All / Cancel」をこの順で表示する。
- 下部バーには現在の一致箇所と全一致数を `n/m` 形式で表示する。m は置換開始時の全一致数、n は現在表示している一致箇所の1始まりの順番とする。
- 一致箇所は専用色でハイライトし、長いメッセージでも一致箇所が画面と編集 textarea の中央付近に来るようにスクロールする。
- 逐次置換および検索モードで一致箇所を表示するために編集 textarea をフォーカスする際は、一時的に読み取り専用かつ `inputmode="none"` とし、モバイル端末のオンスクリーンキーボードを表示しない。処理終了時は通常の編集可能状態へ戻す。
- 逐次置換の `Yes` は現在の一致だけを置換し、`No` は現在の一致を変更せず次へ進み、`All` は現在の一致を含む残りの一致をすべて置換する。`Cancel` は処理を終了し、それまで `Yes` で行った置換は保存する。
- 逐次置換が末尾に達した場合と `all` を選んだ場合は、チャットを保存して「n件置換しました」と表示する。
- 置換後に再検索を続ける位置は挿入した置換ワードの直後とし、置換ワード内を同じ処理で再度置換しない。
- 置換開始前にメッセージを編集中だった場合は、置換処理終了後も同じメッセージの編集表示を復元する。
- 逐次処理中に `Cancel` を選んだ場合は再描画やスクロールを行わず、現在のスクロール位置と、現在一致箇所を表示している回答の編集状態を維持する。
- 置換ワードが空の場合は検索モードとする。検索モードは置換を一切行わず、下部バーを「前へ / 次へ / Cancel」とし、一致箇所間を循環移動できるようにする。進捗表示、中央配置、ハイライト、Cancel時の挙動は逐次置換と共通とする。
